\chapter{Computational modeling of transcription factor-DNA interactions}

Various experimental approaches for TF-DNA interaction analysis result in a set of sequences or genomic regions. They indicate TF specificity towards particular DNA patterns. It allows us to model TF-DNA interactions computationally. A collection of models is available today, from simple and most widely used \ac{PWMs} to the most advanced deep learning models. This chapter will overview different models and techniques that generate them and present a few resources that store such models.

  \section{Transcription factor DNA binding models}

    \subsection{Position weight matrices (PWMs)}

    We need ways to represent the DNA binding to interpret TF binding to the regulatory regions. The most popular and widely used model is the \ac{PWMs} (also called weight matrices or \ac{PSSMs}) ({Figure \ref{tf_dna_models}}) \cite{ambrosini2020insights,weirauch2013evaluation}. PWM assigns scores, representing binding preference and energy, to potential target sequences \cite{ambrosini2020insights,weirauch2013evaluation}. The binding is typically first represented as a matrix of counts of each possible base (A, C, G, or T for a DNA model) at each position in a TF binding site \cite{stormo2013modeling,wasserman2004applied,weirauch2013evaluation}. The matrix length is the length of the DNA motif recognized by the TF \cite{ambrosini2020insights}. It quantitatively describes the known \ac{TFBSs} \cite{wasserman2004applied}. From a set of aligned sequences (for example, processed experimental data or sequences collected from literature) that are bound by a TF of interest, a \ac{PFM} can be computed ({Figure \ref{tf_dna_models}}A-B) \cite{ambrosini2018pwmscan}. A PFM, or a count matrix, is created by counting the occurrences of each nucleotide at each position. Counts can be converted into probabilities to build a \ac{PPM} ({Figure \ref{tf_dna_models}}C) using an equation

    \begin{equation}
      p(b,i)=\frac{f_{b,i}+s(b)}{N+\sum\limits_{b'\in\{A,C,G,T\}}s(b')}
      \label{ppm}
    \end{equation}
    where $ f_{b,i} $ is counts of base $ b $ in position $ i $; $ N $ is the number of sites; $ p(b,i) $ is a probability of base $ b $ in position $ i $; $ s(b) $ is a pseudocount function. Pseudocounts can be added to each cell of the PFM to eliminate zeroes when the number of binding sites is very small \cite{wasserman2004applied}.

    A PWM ({Figure \ref{tf_dna_models}}D) is constructed by dividing the nucleotide probabilities by expected background probabilities and converting the resulting values to a log scale. The most straightforward model assumed equal 0.25 background probabilities for each base. The computation is done using an equation

    \begin{equation}
      W_{b,i}=log_{2}\frac{p(b,i)}{p(b)}
      \label{pwm}
    \end{equation}
    where $ p(b) $ is a background probability of base $ b $; $ p(b,i) $ is a probability of base $ b $ in position $ i $; $ W_{b,i} $ is a PWM value or base $ b $ in position $ i $.

    Frequency or count matrices can be represented in multiple formats. For example, JASPAR format ({Figure \ref{tf_dna_models}}B) visualizes the counts, while MEME format visualizes the probabilities of each nucleotide in each position ({Figure \ref{tf_dna_models}}C). Some computational tools require specific format matrices, so familiarity with different count and probability representations is needed.

    It is difficult to interpret the actual DNA pattern preferentially bound by a TF only by looking at the PWM or PFM matrices. Therefore, sequence logos are used for visualization ({Figure \ref{tf_dna_models}}E). The sequence logo gives information about the frequency of each base at each position and the degree of conservation of each motif position. Sequence logo visualizes \ac{IC} in bits, a basic unit of information. IC can be computed from probabilities using an equation

    \begin{equation}
      D_{i}=2+\sum\limits_{b}p_{b,i}log_{2}p_{b,i}
      \label{ic}
    \end{equation}
    where $ D_{i} $ is the IC in position $ i $, $ p(b,i) $ is a probability of base $ b $ in position $ i $.

    All computational models used to model TF-DNA interactions are based on certain assumptions. One of the most significant limitations of PWMs is that these models assume positions in the binding sequence to be independent \cite{wasserman2004applied,mathelier2013next,weirauch2013evaluation}. Locations of nucleotides at adjoining positions are essential for transcription factor binding, as was demonstrated through biochemical, statistical, and crystal structure analysis \cite{mathelier2013next}. Another possible caveat of the PWMs is that they are limited in modeling compositional binding since homodimers and heterodimers can have a variable spacing between the two binding patterns. PWMs can not predict TFBSs appropriately \cite{wasserman2004applied,mathelier2013next}. One can expand the PWM model to capture additional information, such as DNA methylation. Other TF-DNA interaction models include \ac{TFFMs}, DNA shape-based models. However, despite their limitations, the availability and ease of use keep PFMs and PWMs the primary methods to model TF-DNA interactions.

    \subsection{Other models}

    TFFM models were introduced in 2013 and are based on \ac{HMMs}. They model both position interdependence within TFBSs and variable length motifs, which simple PWM models cannot achieve \cite{mathelier2013next}. It was demonstrated through protein binding array studies that dependencies are more substantial between the neighboring positions in the binding site compared to others \cite{zhao2012improved}. The HMMs allow the modeling of flexible motif lengths because the unconstrained potential for gaps is incorporated at any position. At the same time, TFFMs address interdependencies between nucleotides via a variable-order Bayesian network to model TFBS positions \cite{mathelier2013next}. A new graphical representation, the TFFM logo, visualizes TFFMs position interdependencies. It demonstrates the dinucleotide dependencies but cannot visualize the variable length or spacing of the modeled motif \cite{mathelier2013next}.

    TF binding specificity towards DNA shape is another TF-DNA interaction property that PWMs or TFFMs are not addressing. In DNA shape-based models, PWMs (base readout) are combined with DNA shape features (shape readout), such as helix twist, minor groove width, propeller twist, and roll \cite{mathelier2016dna}. Specific methods, such as DNAshape, compute DNA shape properties \cite{zhou2013dnashape}. Putative TFBSs are predicted in the ChIP-seq peaks using PWMs (or TFFMs). The model predicts DNA shape features at each position of the TFBS. With this information, the classifier is trained to discriminate TF-bound regions from the background \cite{mathelier2016dna}.

    \subsection{\textit{De novo} motif discovery}

    When analyzing TF-DNA interaction data, such as ChIP-seq, one can find over-represented sequence motifs using existing collections of DNA binding motifs (see the section on databases of TF-DNA binding models). However, motif collections are always limited, so to discover new motifs, \textit{de novo} motif discovery approaches have been developed \cite{boeva2016analysis}. \textit{De novo} motif discovery is a process inferring both PWM and the sites \cite{stormo2013modeling}. Researchers developed several computational tools to discover over-represented patterns in DNA sequences. For example, MEME, STREME, RSAT \textit{peak-motifs}, and HOMER. In all of these methods, the aim is to find a short, over-represented DNA pattern in the input set of sequences. Algorithms discover motifs in sequences derived from experimental procedures, such as SELEX, \ac{PBM}, and ChIP-based techniques \cite{boeva2016analysis}.

    MEME is a classical computational tool for detecting over-represented motifs \cite{bailey1994fitting}. The tool analyzes short and small numbers of DNA sequences, limiting its use for analyzing ChIP-seq peaks. To address this, the MEME authors recently published STREME, which allows efficient DNA or RNA analysis of large datasets \cite{bailey2021streme}. STREME finds the motifs that vary from 3 to 30 bp in length and evaluates the enrichment of found matches in the primary set compared to the background \cite{bailey2021streme}.

    RSAT \textit{peak-motifs} is a computational pipeline that integrates several motif discovery algorithms, namely oligo-, position-, and dyad-analysis. All algorithms are generally searching for exceptional motifs in a set of sequences \cite{thomas2011rsat,thomas2012rsat,santana2022rsat}. Oligo-analysis detects over-represented words, while position-analysis identifies oligonucleotides with heterogeneous positional distributions in a provided set of sequences \cite{van1998extracting,helden2000statistical,thomas2011rsat}. By default, word-based analysis performs 6 and 7 bp length motif search. The oligo-analysis estimates expected word frequencies with a Markov model \cite{thomas2012rsat}. Dyad-analysis detects spaced motifs, which dimeric TFs can bind \cite{helden2000discovering,thomas2011rsat}. Researchers observed that regulatory sites in the yeast genome often contain pairs of highly conserved trinucleotides, separated by non-conserved positions \cite{helden2000discovering}. RSAT \textit{peak-motifs} can also perform differential analysis (oligo-diff) when the control set is provided \cite{thomas2012rsat}.

    HOMER was designed to analyze promoters and ChIP-seq data. It searches for enriched motifs in one set of sequences compared to the background set. By default, HOMER motif discovery will search for motifs of lengths 8, 10, and 12 bp by exhaustively screening possible oligos in the target sets and comparing them to the background computes the enrichment using cumulative hypergeometric distribution. The top 200 oligos are selected to calculate PWM. With the custom background set, this differential motif discovery algorithm can compare ChIP-seq peaks in one cell type with peaks in another cell type \cite{heinz2010simple}.

    All the above-mentioned computational tools have their strengths and weaknesses. HOMER and RSAT integrate a useful additional feature that compares discovered motifs with known motifs (read more about motif comparison in the section about the use of TF-DNA binding models). However, one of the main limitations is that these tools aim to discover a single over-represented pattern in a set of sequences at a time. Specialized approaches would be needed to examine the relationship between different discovered patterns. The co-occurring patterns can indicate the TF cooperative binding.

    \subsection{Non-negative matrix factorization for motif discovery}

    A different approach from the above, \ac{NMF}, could be used for DNA pattern discovery in sequences. NMF is one of the matrix factorization techniques. All matrix factorization algorithms generally learn two matrices: amplitude and pattern \cite{stein2018enter}.

    Before applying NMF on genomic sequences, the usual practice is to one-hot encode the nucleotide sequences. It is a classical categorical data processing step for machine learning approaches. Each nucleotide is assigned a unique four-bit long code ({Figure \ref{nmf_motif_discovery}}A). Individual sequences are converted into a numerical array, which then can be passed to the NMF algorithm ({Figure \ref{nmf_motif_discovery}}B). In the learned amplitude matrix, each column stores continuous weights that describe the relative contribution of each sequence in each inferred component. On the other hand, each row in the pattern matrix describes the contribution of each position to a component. \cite{stein2018enter}. Therefore, these two matrices can be used to distinguish subsets of sequences with particular patterns that can be represented as DNA sequence motifs. NMF has a hyperparameter $ k $, instructing how many components should be learned. For example, with $ k = 4 $, four DNA patterns are learned from an input set of DNA sequences ({Figure \ref{nmf_motif_discovery}}C).

    NMF is the basis of a computational tool, seqArchR, to identify position-specific DNA patterns in promoter regions and decipher promoter architectures \cite{nikumbh2023identifying}. It is known that certain DNA motifs inform the selection of TSSs and are located at fixed distances from them. The seqArchR package can identify TSS-directing and lineage-specific motifs, such as TATA or nucleosome position signals. Defining combinations of these motifs can be used to classify promoter architectures and associate them with specific gene regulatory programs \cite{nikumbh2023identifying}.

    NMF algorithms take arrays as the input, meaning the input genomic sequences must be the same length. Another significant limitation is that sequence patterns that NMF can distinguish have to occur at fixed distances. Various patterns can be discovered in separate components, but there must be enough sequences with the same pattern at the exact location. Lastly, a hyperparameter $ k $ can be challenging to define. There are various methodologies, such as the estimation of the cophenetic correlation coefficient, to determine the number of components \cite{brunet2004metagenes}. However, there is no single best way to decide on this parameter.

  \section{Deep learning modeling approaches}

  Nowadays, machine learning, in particular deep learning, is the most state-of-the-art approach for TF-DNA interaction modeling. These approaches address a few critical limitations of the simpler TF-DNA binding models, such as PWM. Some TFs do not have strong motif patterns that could be represented easily with the PWM \cite{wang2022towards}. Furthermore, the more complex TF-DNA interactions, such as TF cooperativity, cannot be conveyed with simple models. Finally, deep learning techniques can integrate multiple factors that define TF binding to the DNA. In addition to the DNA sequence context, chromatin accessibility or DNA methylation can be used to model TF binding \cite{wang2022towards}.

  The current methods can be roughly grouped into three groups: (1) sequence-based methods, which only require DNA sequence data as input and can distinguish regions that are bound by a specific TF or unbound. (2) sequence and shape-based methods, which in addition to the sequence data integrate DNA shape feature information. Such methods model the interplay between nucleotide-amino acid contacts and DNA structural features. (3) sequence and epigenomic profile-based methods, which together with DNA sequence data integrate epigenomic profiling data, such as chromatin accessibility, DNA methylation, or histone modifications. Such models can predict cell-type-specific TF-DNA interactions that are not driven by the DNA sequence alone, but also by epigenetic mechanisms. Trained models are usually evaluated, and their performance is tested \cite{wang2022towards} ({Figure \ref{deep_learning_modeling}}). Motif discovery in the deep learning approaches is performed employing one of two main strategies: feature importance score (perturbation- or backpropagation-based methods) and filter-based approaches \cite{wang2022towards}.

  As mentioned previously, simple TF-DNA interaction models are not generally suited to represent TF cooperativity. Therefore, deep learning approaches are particularly relevant when it comes to deciphering and modeling cooperative transcription factor binding. One of the latest approaches that was used to predict binding profiles of TFs and demonstrated cooperative action is BPNet \cite{avsec2021base}. BPNet is a \ac{CNN} and models the interplay between regulatory sequence and TF binding profiles at base resolution. It consists of multiple convolutional layers and was developed to predict the ChIP-nexus signal in \ac{mESCs} for four TFs (Oct4, Sox2, Nanog, and Klf4). To interpret the results from the BPNet and retrieve the DNA motifs, another tool, TF-MoDISco, is required \cite{shrikumar2018technical}. Motifs are discovered by scanning the regions with high contribution scores, and then performing pairwise alignments and clustering. A motif is derived by averaging the contribution scores at each position for each nucleotide across the aligned sequences. The authors of BPNet in their study demonstrated that their analyzed TFs are binding using soft syntax rules, which means that there are no strict requirements on the numbers of nucleotides in between the two TFs co-binding the region \cite{avsec2021base}.

  \section{Databases of TF-DNA interaction models}

  Researchers started collecting TF binding profiles when more data on TF-DNA interactions became available. Today, several repositories store TF DNA binding motifs. For example, JASPAR, TRANSFAC, HOCOMOCO, and CIS-BP \cite{rauluseviciute2024jaspar,matys2006transfac,wingender2008transfac,vorontsov2024hocomoco,weirauch2014determination}. For the users of such resources, it is essential to understand what data is stored and how it is retrieved and processed. JASPAR is an open-access database and stores DNA binding motifs from six taxa. All motifs in JASPAR are manually curated. JASPAR discovers motifs from experimental data, such as ChIP-seq or DAP-seq, or mined as PFMs from various resources (for instance, a selection of CIS-BP database motifs) and publications. Independent evidence found by curators supports CORE collection motifs. In addition to motif collections, JASPAR provides analyzed data, such as motif clusters and various tools \cite{rauluseviciute2024jaspar}. TRANSFAC also stores curated DNA motifs with experimentally determined and predicted binding sites. However, the complete database is not open-access \cite{matys2006transfac,wingender2008transfac}. HOCOMOCO is a publicly available resource that compiles and stores human and mouse TF binding motifs produced using ChIP-seq or HT-SELEX data. The motifs in this database are human-curated and automatically benchmarked \cite{vorontsov2024hocomoco}. Finally, CIS-BP is also open-access and contains motifs for more than a thousand TFs from 131 diverse eukaryotes. Motifs are generated using \ac{PBM}, SELEX, or ChIP-seq data but are also mined from other motif resources, such as TRANSFAC. A unique feature of CIS-BP is that the database offers inferred motifs. Based on the similarity of the DBDs, two TFs are binding similar motifs. Therefore, it is possible to assume a binding profile from one TF to a closely related other TF \cite{weirauch2014determination}. Specialized databases, such as MethMotif, store cell-type-specific TF binding profiles that are enriched with DNA methylation patterns \cite{dyer2024methmotif}.

  Even if current databases contain thousands of motifs from various species, it is essential to keep these resources updated by adding new data and refining the old. Finally, new ways of TF-DNA modeling (such as deep-learning models) motivate the expansion or creation of new databases that could offer a variety of TF-DNA interaction models to the community.

  \section{Use of TF-DNA binding models}

  Collections of known TF binding profiles can be used in numerous ways. One of the most important applications is the prediction of TF binding sites. Putative TFBSs can be predicted in the entire genome, or TF binding enrichment can be determined in a set of regions. Another popular application of the TF motifs is an annotation of \textit{de novo} discovered motifs, which is important when no binding preferences are known for a TF of interest.

    \subsection{Prediction of TF binding sites}

    TF-DNA binding models can be used to predict putative transcription factor binding sites in the entire genome (also referred to as motif scanning) or a set of regions of interest (for example, ChIP-seq peaks or promoters) \cite{boeva2016analysis}. The TF binding models for predicting can be taken from various databases overviewed in the previous section \cite{rauluseviciute2024jaspar,matys2006transfac,wingender2008transfac}. In the case of search within promoter regions, one can find TFBSs for TFs that possibly are regulating that gene. When searching ChIP-seq peaks, possible co-factor binding can be predicted \cite{boeva2016analysis}.

    In TFBS prediction, the true binding sites are expected to score the highest. However, one of the biggest difficulties is setting the PWM score threshold to determine the final set of those TFBS predictions and separate them from the background \cite{boeva2016analysis}. With the higher score cutoff, fewer motif instances will be found, and the resulting binding sites are likely to correspond to the strong binding affinity, while with the lower cutoff and more sites detected, the sites might represent both strong and weak binding sites \cite{boeva2016analysis}. Usually, statistical significance (measured through \textit{p}-value) is evaluated to solve the issue of thresholding. For example, computing the probability to observe at least the same number of motif instances with a certain cutoff in a random sequence with total length (equal to the total length of sequences in the set of regions of interest) \cite{boeva2016analysis}. This task becomes difficult computationally if multiple motifs (possibly with overlaps) are being scored, which is relevant when investigating TF cooperativity and co-binding.

    Resources, such as JASPAR, in addition to the collections of PFMs, offer TFBS predictions for the most popular genome assemblies \cite{rauluseviciute2024jaspar}. But also there are various tools designed to perform motif scanning or find over-represented motifs in a set of regions. For example, PWMScan, FIMO, or HOMER \cite{weidemuller2021transcription,grant2011fimo,heinz2010simple}.

    PWMScan is a tool for scanning the whole genome with PWM. The cutoff values can be parameterized as match scores or p-values. The program outputs coordinates of the motif instances with their match scores and p-values \cite{ambrosini2018pwmscan}. FIMO also uses PWMs to scan DNA sequences. It calculates a log-likelihood ratio score for each position in the provided sequences. This score is then converted to a p-value. False discovery rate analysis estimates a q-value for each position in the sequence. The result is a score for each motif instance \cite{grant2011fimo}. HOMER is capable of scanning for the motif across the entire genome but also provides a module to screen for the enrichment of known motifs in a set of regions (for example in ChIP-seq peaks) \cite{heinz2010simple}.

    \subsection{Prediction of direct TF binding sites}

    Genome scanning with a motif of interest results in numerous false positives. The resulting predictions of the sites will not be functional \textit{in vivo} even though there is a strong likelihood of TF binding \textit{in vitro}. The phenomenon is known as the futility theorem \cite{wasserman2004applied}. False positively predicted TFBSs are not available for binding due to chromatin structure or local epigenetic properties \cite{mathelier2013next}. It does not mean that such sites are of no importance, but it can be challenging to separate functional TFBSs from non-functional ones.

    Current experimental techniques aim to identify TF binding, but in practice, the data reflect direct and indirect or non-specific TF binding \cite{furey2012chip}. It is challenging to separate the two signals computationally. In addition, while the TFs interact with the DNA through short motifs, the ChIP-seq peaks are usually hundreds of base pairs long. The ChIP-eat computational approach was developed to identify TFBSs that are directly bound by the TF of interest. The method combines ChIP-seq peak data and PWMs to produce sets of direct TFBSs ({Figure \ref{unibind}}) \cite{puig2021unibind,gheorghe2019map}. Given a set of peaks and an optimized PWM of profiled TF, the TFBS enrichment zone is detected. Automatic thresholding identifies the set of TFBSs that are closest to the peak summit and have the highest PWM scores, which is an indication of direct TF-DNA interactions \cite{puig2021unibind,gheorghe2019map}. The resulting TFBSs are of the size of the DNA binding motif. TFBSs from 9 species are provided to the community as a UniBind database \cite{puig2021unibind}. Comparing UniBind TFBSs and predicted TFBSs in the JASPAR database, the conservation of the UniBind ones is much sharper and more concentrated since they are produced using experimental data \cite{puig2021unibind}. But it also shows that the ChIP-eat approach can distinguish functional TFBSs. Therefore, these genomic regions can be a great starting point for further analysis. For example, enrichment analysis can identify, which TFBSs are enriched in a set of regions of interest and which TFs are driving transcription regulation in those regions \cite{puig2021unibind}.

    \subsection{Annotating \textit{de novo} discovered motifs}

    Another use of collections of TF binding profiles is an annotation of \textit{de novo} discovered motifs. When unknown motifs are found, it can be not easy to interpret them. Therefore, motif comparison can indicate the motifs from collections that are the most similar to the ones discovered. For example, the most similar motif could be from the same TF family, indicating that the discovered motif is correct.

    There are computational tools designed to compare the motifs of interest against the provided collection of known motifs. For example, TOMTOM compares the query motif against a database of target motifs. It allows for gapped motif-motif alignments, computes the p-value for each motif, and, finally, performs a Bonferroni correction to derive motif E value. TOMTOM integrates a variety of metrics to score similarity (for example, Euclidian distance and Pearson's correlation) \cite{gupta2007quantifying}. RSAT also has a tool, \textit{compare-matrices}, that is used to annotate discovered motifs when the known motif library is provided \cite{thomas2011rsat,santana2022rsat}. The tool can compare two collections of PWMs and, like TOMTOM uses different similarity scoring functions. Multiple or all metrics can be used in comparison and later summarized by computing the mean rank \cite{thomas2011rsat}.

    \subsection{Prediction of TF co-binding events}

    As with \textit{de novo} motif discovery, predicting TF binding sites is usually limited to individually analyzing each TF binding profile, so deciphering the possible co-occurrence of TF motifs requires specialized tools. For example, SpaMo is a computational tool that analyzes co-binding events using a library of known motifs to detect possible co-binding TFs relative to the indicated primary TF. The method was developed to analyze ChIP-seq data, where the profiled TF is the primary TF. It summarizes the spacing and orientation between the primary and secondary motifs and provides information on the match's significance. The algorithm tests every secondary motif to determine whether the predicted TFBSs have enriched spacing concerning the primary TFBSs \cite{whitington2011inferring}. A significant limitation of SpaMo and similar tools is the requirement of known TF binding motif libraries, meaning unknown DNA patterns are missed by default. In addition, the results can return many significant candidates (secondary motifs), making it difficult to interpret.

    It is crucial to consider the context in which individual TFs are binding. The cooperative binding of multiple TFs in the regulatory regions enables fine-tuning transcription. Therefore, developing computational tools for analyzing such mechanisms is as essential as developing experimental technologies investigating cooperative binding.
